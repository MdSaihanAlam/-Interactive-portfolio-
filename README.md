# Interactive Portfolio

Md Saihan Alam's portfolio as an eight-chapter scroll film. Each chapter has a live canvas scene drawn from the work it describes: a neural network, patch attention, a leaf-disease scan, Grad-CAM with the guava results, a live fall-detection trace, a community graph and the BDPapayaDisease dataset.

- `portfolio.html`: the portfolio (single file, no build step)
- `photo.png`: portrait used in the intro
- `index.html`: the original "Akai Studio" scroll-film demo

Open `portfolio.html` in a browser, or serve the folder (for example `python -m http.server`) so the portrait's background removal works.
